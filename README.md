
## **TrajectAI**

AI-powered Career Roadmap Generator

TrajectAI helps students and professionals discover a clear career path by generating personalized, step-by-step roadmaps based on their interests, strengths, and long-term goals.


## Features

- 🔐 Secure Authentication – Firebase Auth for email/password & real-time session handling.
- 🤖 AI-Driven Planning – Uses OpenRouter API with large-language-model inference to generate tailored roadmaps.
- 🖱️ Interactive Multi-Step Form – Contextual state management for a smooth question-and-answer flow.
- ⚡ Fast & Responsive UI – Built with React.js + Bootstrap for a seamless experience on all devices.
- ☁️ Full-Stack Deployment – Frontend on Vercel, backend on Render, with secure CORS & environment variable management.
